# Atividade: Oracle VirtualBox e Lubuntu

## 1. Objetivo

Instalar o **Oracle VirtualBox**, criar uma máquina virtual e instalar um sistema operacional Linux leve. Nesta atividade, foi utilizado o **Lubuntu**.

O objetivo foi testar o sistema virtualizado e explorar suas principais funcionalidades.

---

## 2. Programas utilizados

- Oracle VirtualBox
- Lubuntu Linux
- Imagem ISO do Lubuntu

---

## 3. Criação da máquina virtual

Após instalar o Oracle VirtualBox, foi criada uma nova máquina virtual para instalar o Lubuntu.

### Configurações da máquina virtual

| Configuração | Valor |
|---|---|
| Nome | Lubuntu |
| Tipo | Linux |
| Versão | Ubuntu (64-bit) |
| Memória RAM | 2 GB |
| Disco rígido | 20 GB |
| Tipo de disco | VDI |
| Armazenamento | Dinamicamente alocado |

---

## 4. Instalação do Lubuntu

Para instalar o Lubuntu, foi utilizada uma imagem **ISO** do sistema operacional.

### Etapas realizadas

1. Abrir o **Oracle VirtualBox**.
2. Criar uma nova máquina virtual.
3. Selecionar o tipo de sistema **Linux**.
4. Configurar a memória RAM.
5. Criar o disco virtual.
6. Inserir a imagem ISO do Lubuntu.
7. Iniciar a máquina virtual.
8. Iniciar o instalador do Lubuntu.
9. Selecionar o idioma e as configurações regionais.
10. Configurar o disco virtual.
11. Criar o usuário e a senha.
12. Aguardar a conclusão da instalação.
13. Reiniciar a máquina virtual.
14. Iniciar o Lubuntu instalado.

---

## 5. Teste do sistema virtualizado

Após a instalação, o Lubuntu foi iniciado dentro do VirtualBox para verificar seu funcionamento.

Foram realizados testes das seguintes funcionalidades:

- Inicialização do sistema;
- Área de trabalho;
- Teclado e mouse;
- Conexão com a Internet;
- Navegador;
- Gerenciador de arquivos;
- Terminal;
- Configurações do sistema;
- Instalação de programas;
- Desligamento e reinicialização.

---

## 6. Principais funcionalidades do Lubuntu

### 6.1 Área de trabalho

O Lubuntu possui uma interface gráfica simples e leve, permitindo acessar aplicativos, arquivos e configurações do sistema.

### 6.2 Gerenciador de arquivos

O gerenciador de arquivos permite:

- Criar pastas;
- Criar arquivos;
- Copiar arquivos;
- Mover arquivos;
- Renomear arquivos;
- Excluir arquivos;
- Organizar documentos.
